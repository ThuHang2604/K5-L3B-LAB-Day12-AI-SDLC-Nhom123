# Quán Ăn Chợ Nổi v1.0.0 — Nhom123

Út Sen lặn sông Chín Khúc buổi sáng, tối phụ Má Tư mở quán trên nhà bè. Bản phát hành cuối buổi lab Day 12 (Test Contract v1.3).

## Điểm mới
- **Vòng 5 Ngày hoàn chỉnh:** Menu → DayIntro (Má Tư đọc món) → Lặn & Hái → EveningIntro → Mở Quán → DayResult → Shop nâng cấp → … → Tổng kết.
- **Buổi sáng:** oxy/ngạt/Máu, 8–12 đàn cá bơi (cá linh, cá lóc, cá kèo), hái bông điên điển/bông súng/kèo nèo, Cá Sấu Năm Chèo tuần tra và đuổi ở vùng sâu.
- **Buổi tối:** 2 bếp, 4 bàn, 6 món miền Tây, giữ chỗ nguyên liệu, kiên nhẫn, boa và uy tín.
- **Mùa Nước Nổi (v1.2):** mỗi nguyên liệu là một cá thể có độ tươi; hàng ươn không nấu được; giá món theo độ tươi.
- **Phát hành (v1.3):** `bench_cmd` (benchmark có render 1280×720), `soak_cmd` (10 Ngày headless bằng bot tất định), cảnh báo bằng chữ + biểu tượng (thủy quái gần, sắp hết oxy, khách sắp giận), **chế độ tương phản cao** (phím H, nhớ giữa các lần mở).

## Cách chạy (Python ≥ 3.10, chỉ thư viện chuẩn)
```bash
git clone https://github.com/<owner>/K5-L3B-LAB-Day12-AI-SDLC-Nhom123.git
cd K5-L3B-LAB-Day12-AI-SDLC-Nhom123
python3 -m chonoi.live        # mở http://127.0.0.1:8000/
```
Hoặc tải `quan-an-cho-noi-v1.0.0.zip` đính kèm, giải nén, `cd` vào thư mục và chạy lệnh cuối.

- Test: `PYTHONPATH=tests:. python3 -m unittest discover -s tests -v`
- Headless: `python3 -m chonoi.headless --mode day --days 5 --seed 42 --ticks 111000 --out out.jsonl`
- Benchmark: `python3 -m chonoi.bench --seed 42 --duration 30 --out bench.json`
- Soak: `python3 -m chonoi.soak --seed 7 --days 10 --out soak.json`

## Số đo trên máy của nhóm
Xem `docs/proof/phase-4/bench.json` và `soak.json` (renderer, FPS, 1% low, thời gian tải; 10/10 Ngày, 0 crash).
